# engram stats

Show aggregate statistics across all engrams.

## Usage

```bash
engram stats
```

## Description

Displays aggregate statistics including:

- Total number of engrams
- Breakdown by agent and capture mode
- Total tokens consumed and estimated cost
- Date range of sessions

## Examples

```bash
# Show stats
engram stats

# JSON output
engram stats --format json
```
